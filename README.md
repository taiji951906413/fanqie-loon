# 番茄系 App 去广告 · Loon 远程版

一个 Loon 插件，减少**番茄小说 / 番茄畅听 / 红果短剧**三款 App 里的广告。

两层处理：拦截穿山甲（巨量引擎）广告 SDK 与埋点域名；信息流广告由远程脚本改写响应、剔除带广告标记的条目。

不修改 App，不需要改动手机系统，不影响账号登录。手机上直接导入，不用电脑。

## 能去掉什么

| 广告类型 | 出现在哪 | 效果 |
|---|---|---|
| 开屏广告 | 启动第一屏 | 去掉 |
| 激励视频 | 金币任务页 | 去掉（代价：领不到这部分金币） |
| Banner / 插屏 | 各页面 | 去掉 |
| 信息流混排广告 | 首页、推荐流 | 远程脚本改写，可去掉 |
| 章节末尾广告 | 阅读器内 | 部分去掉 |
| 短剧贴片广告 | 红果播放页 | 去不掉（视频流） |

信息流广告为什么拦域名没用：它不是单独请求来的，是服务端和正常内容混在同一个列表里下发的。域名拦截挡不住已经混进业务数据的条目，只能在响应返回途中改写。

## 前置条件

- iPhone / iPad，已装 Loon 并能正常使用
- **装并信任 Loon 的 MITM 证书** —— 插件里 `[Script]` 和 `[MITM]` 默认是开启的，不装证书脚本不执行
- 三款 App 至少装一款（插件对三款同时生效）

## 安装

### 方式一：在线导入（推荐）

复制插件地址，Loon → 配置 → 插件 → 右上角 `+` → 粘贴 → 保存：

```
https://cdn.jsdelivr.net/gh/taiji951906413/fanqie-loon@main/fanqie.plugin
```

### 方式二：从文件导入

下载 `fanqie.plugin`，存到「文件」App（iCloud Drive 或 我的 iPhone 都行），
Loon → 配置 → 插件 → 右上角 `+` → 从文件导入 → 选这个文件。

### 装证书

Loon → 配置 → 证书 → 生成并安装 → 去 iOS「设置」安装描述文件 → 通用 → 关于本机 → 证书信任设置 → 打开 Loon 的开关。

不装证书，`[MITM]` 不生效，远程脚本不会执行，信息流广告也就去不掉。

## 三个档位

`[Rule]` 段按风险分了三级，A 和 B 默认开启：

- **档位 A** — 穿山甲 / 巨量引擎广告 SDK。开屏、激励视频、Banner 走这里，拦掉后广告位空白，不影响阅读听书看剧。
- **档位 B** — 埋点与监控。只是少上报，没有副作用。
- **档位 C** — 默认注释掉。`log.snssdk.com` 是 AppLog 主通道，部分版本登录/风控也复用；`gurd.snssdk.com` 是设备注册。拦了可能触发「环境异常」，想试就去掉行首 `#`，随时准备改回来。

### 绝对不要拦这几个

拦了 App 直接不可用（白屏 / 加载不出封面）：

```
api5-normal-sinfonlinea.fqnovel.com   主 API
reading.snssdk.com                    H5 页面 / 接口
api.fqnovel.com
lf3-reading.fqnovelpic.com            封面 / 插图 CDN
```

## 看日志

脚本默认同时做两件事：过滤广告条目，以及每遇到一个**没见过的接口结构**就打一次日志（结构签名去重，不会刷屏）。

刷十几屏，然后看 Loon → 首页 → 脚本日志：

```
[fanqie:new-schema]
URL https://api5-normal-sinfonlinea.fqnovel.com/reading/feed/v1
TOP code,message,data
ARR $.data.cell_list len=20 ads=2/20 AD? keys=cell_id,cell_type,book_data,...
    +keys(ad)=ad_info,cid,log_extra
```

- `len=20 ads=2/20` — 这个列表 20 条，其中 2 条被判为广告
- `AD?` — 有广告；没这个标记说明这条接口是干净的
- `+keys(ad)=...` — 广告条目比正常条目多出来的字段

脚本内置两个保护：某个列表里所有条目都被判成广告（且长度 ≥ 3）时，认为误判、放弃删除并在日志打 `guarded=`；没识别到广告就原样放行，不重写内容。

## 临时关闭过滤

Loon 里的远程脚本是只读的，改内容下次拉取会被覆盖，所以不靠「改脚本切模式」。要临时关掉，在 `[Script]` 那行的 `script-path=` 后面追加参数：

```
, argument="MODE=off"      完全放行，只保留域名拦截
, argument="MODE=log"      不改内容，每次请求都打结构（深挖字段用）
```

改不了插件文本的话，直接禁用整个插件即可。

## 国内访问提示

脚本地址默认用 `raw.githubusercontent.com`。国内部分网络访问 raw 不稳定，如果日志里一直空白、脚本没执行，把 `[Script]` 里的 `script-path=` 换成 jsDelivr：

```
https://cdn.jsdelivr.net/gh/taiji951906413/fanqie-loon@main/fanqie_ad_filter.js
```

注意 jsDelivr 有缓存，脚本更新后不会立刻生效。

## 风险与已知限制

- **证书校验**：部分接口会校验证书，开启 MITM 后某页面一直转圈或提示网络异常，就把对应域名从 `[MITM]` 的 `hostname` 里去掉
- **视频流广告无解**：短剧贴片走视频流，改内容处理不了
- **QUIC 可能绕过代理**：日志里完全看不到某域名请求但广告在加载，可能走了 QUIC（UDP 443），排查时临时加 `AND,((PROTOCOL,UDP),(DEST-PORT,443)),REJECT`，用完删掉
- **改写响应有风控风险**：服务端若做完整性校验可能报错，目前没遇到，建议先用小号试
- **拦广告的副作用**：激励视频被拦 = 领不到那部分金币；开屏广告位变空白或跳过；「看广告解锁」的功能会失效

## 常见问题

**装完完全没效果？**
确认插件是启用状态、Loon 在运行（有 VPN 图标），再看日志里有没有对应域名请求。连记录都没有说明流量没走 Loon。

**开屏没了，首页还有广告？**
确认证书装好并信任了。信息流过滤依赖 MITM，证书没信任时脚本不执行。

**装完 App 打不开 / 白屏？**
大概率误拦了主接口。核对上面「绝对不要拦这几个」的域名，或者临时禁用整个插件确认是不是插件导致的。

**日志里什么都没有？**
三种可能：证书没装或没信任、`[Script]` 或 `[MITM]` 段被删了、这条接口没被规则匹配到。

**金币领不到了？**
激励视频被拦了。想领就临时禁用插件，领完再开。

**会影响其它 App 吗？**
不会。规则只针对这三个 App 相关域名，`[MITM]` 也只对这些域名生效。

**能用在安卓上吗？**
不能。Loon 是 iOS 独占的。
