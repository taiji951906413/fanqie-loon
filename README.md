# 番茄系 App 去广告 Loon 插件

一个 Loon 插件，用来减少**番茄小说 / 番茄畅听 / 红果短剧**三款 App 里的广告。
靠拦截广告 SDK 域名实现，可选加一层响应内容过滤处理信息流广告。

不修改 App，不需要改动手机系统，不影响账号登录。

## 能去掉什么

**只装插件（不用装证书）**
- 开屏广告
- 激励视频（代价：领不到这部分金币）
- Banner / 插屏

**装了证书 + 脚本才能去掉**
- 信息流混排广告（首页、推荐流）
- 章节末尾广告（只能去掉一部分）

**去不掉**
- 短剧贴片广告，走视频流，改内容处理不了

## 安装

1. 复制插件的在线地址（见下）
2. Loon → 配置 → 插件 → 右上角 `+` → 粘贴地址
3. 保存后先只用「档位 A / B」，「档位 C」是风险项，默认注释掉
4. 跑两天，确认登录、阅读、进度同步都正常

插件地址（二选一，国内优先 jsDelivr）：

```
https://cdn.jsdelivr.net/gh/taiji951906413/fanqie-loon@main/fanqie.plugin
https://raw.githubusercontent.com/taiji951906413/fanqie-loon/main/fanqie.plugin
```

也可以把 `fanqie.plugin` 下载下来，存进「文件」App，再用「从文件导入」。

## 进阶：信息流广告过滤

需要装并信任 Loon 的 MITM 证书，会改动返回内容，**建议先用小号试**。

1. Loon → 配置 → 证书 → 生成并安装 → 去 iOS「设置」安装描述文件 → 通用 → 关于本机 → 证书信任设置 → 打开 Loon 开关
2. 编辑插件，把 `[Script]` 里 `http-response` 那一行、`[MITM]` 里 `hostname` 那一行的 `#` 去掉
3. 刷一刷 App，去 Loon → 首页 → 脚本日志看输出

脚本地址已经写在插件里，不用手动改：

```
https://cdn.jsdelivr.net/gh/taiji951906413/fanqie-loon@main/fanqie_ad_filter.js
```

日志里 `len=20 ads=2/20` 表示 20 条里 2 条被判为广告，`AD?` 表示这条接口有广告。
同一种结构只打一次，不会刷屏。

脚本内置两个保护：整页条目全被判为广告时会放弃删除（日志打 `guarded=`），没识别到广告就原样放行。

## 文件说明

| 文件 | 说明 |
|---|---|
| `fanqie.plugin` | Loon 插件本体，直接导入用 |
| `fanqie_ad_filter.js` | 信息流过滤脚本，插件里已引用，无需单独下载 |

## 已知限制

- 部分接口会校验证书，开启 MITM 后某页面一直转圈，就把对应域名从 `hostname` 里去掉
- 短剧贴片广告走视频流，无解
- 广告可能走 QUIC（UDP 443）绕过代理，排查时临时加 `AND,((PROTOCOL,UDP),(DEST-PORT,443)),REJECT`，用完记得删
- 改写响应内容有风控风险，目前没遇到，但建议先用小号试
